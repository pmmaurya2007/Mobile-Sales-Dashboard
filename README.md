# 📱 Mobile Sales Dashboard | Power BI

An interactive Mobile Sales Dashboard built using Microsoft Power BI to analyze mobile sales performance and generate business insights.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📊 Dashboard Features

- Total Sales
- Total Units Sold
- Transaction Count
- Average Price
- Brand-wise Sales Analysis
- Top Mobile Models
- Monthly Sales Analysis
- Daily Sales Analysis
- Payment Method Analysis
- Customer Age Group Analysis
- City-wise Sales Analysis
- Interactive Filters & Slicers

## 🔍 Key Analysis

The dashboard provides insights into:

- Sales performance by mobile brand
- Top-performing mobile models
- Monthly and daily sales trends
- Customer age-group distribution
- Payment method distribution
- City-wise sales performance
